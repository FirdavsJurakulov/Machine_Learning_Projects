How a prediction is made

  1. Preprocess. The drawing is cropped to its ink, scaled so its longer side is 20 pixels, and shifted so its center of mass sits in the middle of the 28 × 28 frame. MNIST digits were prepared the same way, so without this step the network sees inputs unlike anything it trained on.
  2. Hidden layer. The 784 pixel values (0 to 1) are multiplied by a 784 × 128 weight matrix, the bias is added, and ReLU keeps only the positive results.
  3. Output layer. A 128 × 10 matrix turns those 128 activations into one score per digit, and softmax converts the scores into probabilities that add up to 100%.

The weights were learned in Python with mini-batch gradient descent and backpropagation. This page only runs the forward pass, the same math as NeuralNetwork.forward.
